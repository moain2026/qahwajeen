# 02 — نظام التصميم

> **زمرّدي داكن + ذهبي. لا خلفيات بيضاء.** فخم، بسيط، سريع، موثوق.
> ملف تنسيق واحد: `public/static/style.css` (72 KB، 14.5 KB مضغوط) — جزء
> مضغوط بـ csso + قواعد مقروءة مُلحقة في آخره (v4 / v4.1).

## 1. القواعد الثابتة

1. **زر رئيسي واحد في كل شاشة** — وكل عنصر يقود إلى اتصال أو واتساب.
2. **كل هدف لمس ≥ 44×44 بكسل** (يفحصه `qa/scripts/btn.py` على 320/390/1440).
3. **لا فائض أفقي** على 320 و390 بكسل.
4. **الحركة `transform`/`opacity` فقط** وتتوقف مع `prefers-reduced-motion`.
5. **عند تعديل CSS/JS ارفع `V`** في `src/layout.tsx`.
6. **لا تشغّل purgecss** على الملف — يحذف قواعد مستخدمة. الحذف يكون بعد
   قياس المحدّدات المطابقة فعلًا في المتصفح ومقارنة لقطات بالبكسل.

## 3. 🔴 الطباعة العربية — أهم قسم في هذا الملف

### الخطأ الذي وقعنا فيه فعلًا وكلّفنا شكوى مباشرة من العميل

استخدمنا `line-height: 1.16` للعنوان الرئيسي — وهي قيمة **لاتينية سليمة
تمامًا**. النتيجة: **تشابك الخطوط** (`تشابك الخطوط` بنص العميل).

**السبب التقني الدقيق:**
خط Amiri العربي فيه ثلاث طبقات رأسية لا توجد في الخطوط اللاتينية:
1. **صواعد طويلة**: ل، ك، ط، ظ، أ
2. **نوازل عميقة**: ج، ح، خ، ع، غ، ي، ن
3. **التشكيل فوق خط الحد الأعلى** (فتحة، شدّة، مدّة) — وهذا ما لا يحسبه
   أي مطوّر آتٍ من الويب اللاتيني.

مجموع الثلاثة يعني أن الصندوق البصري للسطر العربي **أطول بنحو 25٪** من
نظيره اللاتيني بنفس `font-size`.

### الحدود الدنيا الآمنة — لا تنزل عنها

| العنصر | الحد الأدنى | ملاحظة |
|---|---|---|
| `h1` | **1.44** | كان 1.16 وتشابك |
| `h2` | **1.42** | |
| `h3` | **1.46** | |
| `h4` | **1.50** | أصغر حجمًا ⇒ يحتاج نسبة أكبر |
| نص أساسي | **1.42** | |

**الدليل المقيس:** المسافة بين خطي العنوان الرئيسي انتقلت من
**35.96 بكسل → 44.64 بكسل** بعد التعديل.

### 🔴 تباعد الأحرف: العربية خط متّصل

كان `.eyebrow { letter-spacing: .24em }` — وهي حيلة فخمة معروفة في
التصميم اللاتيني. في العربية **تمزّق وصلات الحروف** وتجعل الكلمة تُقرأ
حروفًا منفصلة.

```css
/* ❌ .24em — تمزّق الوصلات */
/* ✅ الحد الأقصى المسموح: */
letter-spacing: .06em;
```

## 4. المكوّنات الرئيسية

| المكوّن | الصنف | ملاحظات |
|---|---|---|
| الترويسة | `.hdr` | صف واحد: شعار · زر اتصال · زر القائمة. القائمة على الجوال `#topNav` (Esc يغلق) |
| الشريط السفلي | `.bnav` | زرّان فقط: واتساب · اتصال. يختفي ما دامت أزرار البطل ظاهرة |
| البطل | `.hero` | صورة حقيقية + بطاقة زجاجية + زر رئيسي واحد |
| عنوان القسم | `.sx-head` (`Head`) | مؤشّر صغير + H2 + خط ذهبي + سطر فرعي |
| الأزرار | `.btn-gold` (رئيسي) · `.btn-line` (ثانوي) | `min-height:48px` |
| أقسام التقديمات | `.mcat` · `.mcat-count` · `.mcat-items` · `.mcat-order` · `.mcat-nav` | صورة + عدد + اسم + سطر + أصناف + زر «اطلب» |
| روابط الطاقم | `.mcrew` · `.mcrew-it` | |
| بطاقات المناسبات | `.arr-card.arr-ph` | صورة أعلى البطاقة |
| نافذة الصور | `.lbx` · `.lbx-top` · `.lbx-fig` · `.lbx-bar` | ثلاث صفوف؛ الأزرار لا تغطي الصورة أبدًا؛ `html.lbx-on` يقفل التمرير |
| روابط التذييل | `.ftr-links` · `.ftr-seo` | الصفحات الرئيسية + صفحات جدة |
| الأسئلة | `.faq` (`Faq`) | `<details>` — سؤال واحد مفتوح |

## 5. HTML دلالي

- `<header> <nav> <main> <section> <article> <footer>`؛ `<dialog>` لنافذة الصور.
- H1 واحد في كل صفحة (يفحصه `index_audit.py`).
- الصورة الزخرفية `alt=""` والصورة ذات المحتوى نص بديل وصفي.
- لا إيموجي ولا خطوط أيقونات — SVG من `src/icons.tsx`.

## 6. الحركة

- `.rv` → `.in` عند الظهور (المحتوى ظاهر بدون JS).
- حركة البطل (Ken-Burns، الأشعة، الذرّات) تبدأ بعد `html.go` فقط.
- `@media (prefers-reduced-motion: reduce)` يوقف كل شيء.
