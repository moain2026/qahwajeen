### `MenuCat`
```ts
{ slug, cat, line, icon, hero, blurb, items: { n, d, img? }[] }
// cat  = اسم القسم الظاهر ("المشروبات الحارة")
// line = سطر الوصف الواحد تحت الاسم
// hero = صورة القسم
// items[].n = اسم الصنف (يظهر)، d = وصف قصير (في JSON-LD MenuItem)
```
ترتيب الأقسام = ترتيب المصفوفة = ترتيب keifaldiafa.com/offerings:
الحارة · الباردة · التمور · الحلويات · المعجنات · المقبلات · الساندويتشات · الفواكه · الشعبية والمكسّرات.

زر «اطلب {القسم}» يفتح واتساب برسالة `orderMsg()` في `onepage.tsx`:
```
السلام عليكم، أرغب بإضافة «{القسم}» لمناسبتي:
التاريخ:
الحي:
عدد الضيوف:
```

### `Shot` (المعرض)
```ts
{ img, cap, tall?, cat }   // cat ∈ فريق · ملكية · عدّة · تقديمات · إضافات
```
`cap` = النص البديل والتعليق في نافذة العرض و`caption` في JSON-LD — اكتبه وصفًا لما في الصورة.

## 3. قواعد المحتوى (ثابتة)

- لا أسعار، لا باقات، لا تقييمات، لا شعارات شركاء.
- لا ادعاءات غير قابلة للإثبات: ٢٤/٧، «خلال دقائق»، «١٠ ثوانٍ»، ١٠٠٪، فواتير، مدن غير جدة.
- رقم واحد للاتصال والواتساب، والبريد هو القناة الثالثة الوحيدة.
- «من نحن» و«تواصل» = `/links` فقط.

## 4. وصفات

| أريد | الخطوات |
|---|---|
| تعديل نص | ابحث عنه في `data.ts`/`jeddah.ts` وعدّله · حدّث `CONTENT_DATE` |
| صنف جديد في المنيو | أضفه في `items` للقسم المناسب — يظهر في الصفحة وJSON-LD |
| صورة في المعرض | أضف الملف و`imgmap.ts` ثم سطر `{ img, cap, cat }` في `GALLERY` — تدخل خريطة الموقع تلقائيًا |
| صفحة جدة جديدة | كائن جديد في `JEDDAH_PAGES` بنص فريد كامل (`h1`, `body`, `bullets`, `faq`) — المسار والتذييل وخريطة الموقع تلقائية |
| تفعيل GA4/Ads | املأ `TRACKING` — انظر `README.md` القسم 5 |
| تحقق Search Console | الصق قيمة `content` في `SEARCH.googleVerify` |

بعد أي تعديل: `python3 qa/scripts/index_audit.py && python3 qa/scripts/seo.py`.
